Variables · Scratch maze game

Lives Lab

A variable is a named box that holds one value. The game looks inside the box whenever it needs to know something, and the value can change while the game runs.

  1. Play. Escape the maze. Watch the lives, score and moves boxes.
  2. Predict. Press the green flag and tick Predict mode. Before every move, tell your partner what will be in each box. Click a box to check.
  3. Explain. Which blocks make a box go up? Which make it go down? Which one puts a brand new value in?

The maze

Arrow keys or buttons. Touch a wall and you lose a life. Yellow coins are worth 10. The red heart gives a life back.

Variables

Each box shows the value stored right now, and the value it had before.
