Scratch Bonus Missions

Four extra projects that use what you learned in the knock knock joke, the Etch a Sketch and the maze game. Each one has a list of what it must do, some level-ups for when you want more, and hints that give you clues, not code.

Mission rules

  1. Plan first. Say out loud what your sprite should do, step by step.
  2. Build a little, then test. Click the green flag after every change.
  3. Stuck? Open one hint. Try it before you open the next one.
  4. No copying code from anywhere. If you can't explain a block, it isn't yours yet.
  5. When you finish, answer the Explain it question for your teacher.
Before you ask the teacher

Bug hunting checklist

Most bugs are found with one of these. Work down the list.

  1. Right sprite? Check the code is on the sprite that should do the job, not on the stage or another sprite.
  2. Does it start? Every script needs a hat block on top. Which event starts this one?
  3. Read it out loud. Read each block in order, like the computer. Say what happens after each one.
  4. Test one piece. Click a single script to run just that part. Does it do what you expected?
  5. Show the value. Tick the box next to a variable so you can see it on the stage while the game runs.
  6. Too fast to see? Add a short wait so you can watch what is happening.
  7. Explain it to a partner. Talking through your code often shows you the mistake.
