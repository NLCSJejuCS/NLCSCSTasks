How high can you hear?

Humans hear roughly 20 Hz to 20,000 Hz, and younger people hear higher. This slider changes the pitch of the sound, which is a different thing from the sample rate.

Going further: why 44,100 Hz?

To record a sound accurately you need at least two samples for every wave cycle. The highest sound we hear is about 20,000 Hz, so we need more than 40,000 samples a second. CDs use 44,100 Hz. Try the tune at 4,000 Hz: the higher notes sound wrong because there are too few samples per cycle.

Station 4

Sample it yourself

You are the ADC. At each time point, read the height of the wave and round it to the nearest whole number (0 to 15). You can only record a value on a grid line. Answers within 1 of the true value count as correct.

Station 5

Store the samples in binary

With a 4-bit resolution there are 24 = 16 values (0 to 15), so every sample is written as exactly 4 bits. Convert each sample to 4-bit binary. Place values: 8 4 2 1.

Station 6

Calculate the file size

Use the formula, then convert units if the question asks. In the 0478 syllabus, 1 KiB = 1024 bytes and 1 MiB = 1024 KiB.

file size (bits) = sample rate (Hz) × resolution (bits) × duration (s)
bytes = bits ÷ 8  ·  KiB = bytes ÷ 1024  ·  MiB = KiB ÷ 1024
