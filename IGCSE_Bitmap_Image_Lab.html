      Station 7
      
Calculate the file size

      
An uncompressed bitmap stores one value for every pixel, so: file size = width × height × colour depth. That gives bits. Divide by 8 for bytes, then by 1024 for KiB.

      Station 8
      
Estimate a document

      
A document can hold text and pictures. In ASCII each character, including spaces, takes 1 byte. A colour picture uses 3 bytes per pixel (one each for red, green and blue). A greyscale picture uses 1 byte per pixel. Edit the text and the pictures to see the total.

    

    

      

      
Pictures

    

    

    
Divide by
      

        

    

    

      See it as an algorithm with a trace table
      
total ← LENGTH(text)
FOR each picture
   pixels ← width * height
   IF mode = "colour" THEN
      bytes ← pixels * 3
   ELSE
      bytes ← pixels
   ENDIF
   total ← total + bytes
NEXT picture
OUTPUT total, " bytes"

      

    

    
A real file is a little bigger than this estimate because it also stores formatting, fonts and metadata.
